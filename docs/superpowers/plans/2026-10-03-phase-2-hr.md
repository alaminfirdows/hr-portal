# Phase 2 — HR (Leave + Attendance) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Leave management with configurable approvals and accrual; attendance with web check-in, finalize job, HR corrections.

**Architecture:** Two modules `modules/Leave`, `modules/Attendance`. Leave implements `LeaveCalendar`; Attendance implements `AttendanceSummary` and listens to Leave events. Holidays + `WorkCalendar` come from Organization (Phase 1).

**Tech Stack:** as Phase 1.

**Spec:** `docs/superpowers/specs/2026-10-03-hr-portal-design.md`; rules in `docs/PROJECT_CONTEXT.md` §6.

## Global Constraints

- Only touch `modules/Leave/**` and `modules/Attendance/**` (plus their own tests). Use Shared contracts for cross-module reads.
- Leave days computed with `WorkCalendar`. Balances decimal(6,2).
- Permissions: `leave.request`, `leave.view`, `leave.approve`, `leave.manage` (types/balances), `attendance.check_in`, `attendance.view`, `attendance.manage`, `shifts.manage`.

## Review Focus

1. Leave range spanning weekend + holiday → days counts only working days; range with zero working days rejected.
2. Overlapping request (pending or approved) → rejected with clear error.
3. Employee without manager on `["manager","hr"]` type → goes straight to HR step.
4. Manager approving own leave request → 403.
5. Leave approved after `attendance:finalize` marked day absent → record becomes `on_leave`; check-in record already `present` is not overwritten.

### Task 1: Leave types + balances
- Files: migrations leave_types, leave_balances; models, enums `AccrualMethod`, `DayPart`, `LeaveStatus`, `ApprovalStepRole`; factories; `LeaveTypeController` + page `leave/types/index.tsx` (dialog form); `Services/LeaveBalanceService` (`available(Employee|int, LeaveType, int $year): ?float` null = unlimited, `forEmployee(int $employeeId, int $year)`); Actions `AllocateYearlyBalances(int $year)`, `AccrueMonthlyBalances(CarbonInterface $month)`, `AdjustBalance`; commands `leave:allocate {year?}`, `leave:accrue`.
- Tests: yearly allocation full quota; pro-rata joiner (joined July → 6/12); carry forward capped; monthly accrual adds quota/12 once per month (idempotent); unlimited quota returns null.

### Task 2: Leave requests
- Files: migrations leave_requests, leave_approvals; `Services/LeaveDayCalculator`; Actions `SubmitLeaveRequest`, `ApproveLeaveRequest`, `RejectLeaveRequest`, `CancelLeaveRequest`; `Services/ApprovalFlow` (resolve next step, skip rules); events `LeaveRequestSubmitted/Approved/Rejected/Cancelled` (Auditable); notifications to approver(s) and employee; `Services/EloquentLeaveCalendar` implements `LeaveCalendar`; attachment stored private, download route with policy.
- Controllers/pages: `leave/requests/index.tsx` (my requests + balances cards + new request dialog), `leave/approvals/index.tsx` (pending for me; filters dept/team/type/status/date), `leave/requests/show.tsx` (timeline of approvals), `leave/calendar.tsx` (month grid of approved leave in visible scope + holidays).
- Tests: days calculation; half-day only single day + allowed type; insufficient balance; overlap; max consecutive; attachment required; flow manager→hr; skip manager when none; HR can act on manager step; self-approval forbidden; reject ends flow + releases pending; cancel pending; cancel approved future restores used; cancel past approved forbidden; manager sees only team in approvals; balance moves correct.

### Task 3: Attendance core
- Files: migrations shifts, employee_shifts, attendance_records; enums `AttendanceStatus`, `AttendanceSource`; `Services/AttendanceEvaluator` (status/late/overtime from shift); Actions `CheckIn`, `CheckOut`, `UpsertAttendanceRecord` (HR manual), `FinalizeAttendanceDay(CarbonInterface $date)`; listeners on Leave approved/cancelled; command `attendance:finalize {date?}` scheduled 23:55; `Services/EloquentAttendanceSummary` implements `AttendanceSummary`.
- Controllers/pages: `attendance/my.tsx` (check-in/out card + month list), `attendance/records/index.tsx` (HR/manager table with filters + edit dialog), `attendance/shifts/index.tsx` (CRUD + assign employees).
- Tests: check-in twice rejected; check-out before check-in rejected; late detection with grace; half day; overtime; finalize writes weekend/holiday/on_leave/absent; finalize idempotent; leave approved → on_leave rows; present not overwritten; manual edit audited; manager sees team only.

### Task 4: Widgets + navigation
- Widgets: Leave (my balances, pending approvals count, who's on leave today), Attendance (today's status / check-in button link, team attendance today, attendance summary for HR).
- Navigation group "Time off" and "Attendance".
- Demo seeder: leave types (Annual 18 yearly carry 5, Sick 10 yearly, Casual 8 monthly, Maternity 112, Paternity 10, Unpaid unlimited), balances, ~40 requests mixed statuses; default shift 09:00–18:00 grace 15; 30 days of attendance.
